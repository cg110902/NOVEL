# craft_drafter.md — 起草先锋爆发力手册（Drafter 专版）

本文档是 Stage 2 初稿起草子代理（Drafter）的**通用起草实战手册**（适用于全题材）。
核心理念：**彻底解除机械教条与禁词束缚，全力释放算力，专心讲好故事，拉满冲突碰撞、反差与人物张力！**

---

## 🎯 Drafter 的核心使命
将 Stage 1 细纲任务书（beats）与上章余温，转化为**情节饱满、情绪高昂、对白生动、画面感强**的高能初稿毛坯（`manuscript/vol_XX/raw/ch_XXX_v1.md`）。

---

## 一、 四大核心起草武器

### 1. 🎬 动态场景切片与极速切入法（杜绝慢热）
- **拒绝开篇设定说明会**：严禁在章首大段解释世界观、系统规则或心路历程，开篇必须以**“动作突袭 / 危机发生 / 对话直接交锋 / 现场盘点 / 突发事件”**直接切入；
- **镜头感调度**：把文字当电影镜头来写——先给特写（刀锋逼近、微表情动作、信物异动、仪器警报），再拉全景（环境氛围、在场群体反应）；
- **推进 2~4 个场景切片**：严格依照 beats 中划分的 Scene 切片有序推进，各场景之间转场利落、不拖泥带水。

### 2. 📈 依据多元张力曲线（1-10分）动态调节叙事呼吸感
- **多元张力波形自适应**：
  - **爬坡高潮型 (4 ➔ 7 ➔ 9)**：开篇铺垫施压，中段冲突激化，结尾高潮反杀或强钩引爆；
  - **高开余波型 (9 ➔ 5 ➔ 7)**：章首直接切入白热化交锋/危机，中段转入战后清点或战术休整，末尾暗流再起；
  - **智斗波浪型 (6 ➔ 4 ➔ 8 ➔ 5)**：试探交锋 ➔ 喘息分析 ➔ 突发反转 ➔ 尘埃落定；
  - **蓄势探索型 (3 ➔ 5 ➔ 6)**：日常生活、新地图调查或线索伏笔回响，语调舒缓自然。
- **句式长短与动词密度**：
  - **低/中张力 (3-6分)**：生活化描写与长短句交替，铺陈环境细节与人物试探；
  - **高张力 (7-10分)**：**全面采用短句与高密动词**！砍掉抽象形容词，雷霆破局，节奏拉满！

### 3. 🎭 人物声纹口吻精准锚定（锁死 Voice Profile，千人千面）
- **句式与语速习惯严格对齐人物卡**：主角和配角拥有各自鲜明的语言风格；
- **严守绝对语言禁忌（Negative Constraints）**：坚决不让角色说出与其人设背离的台词（如高冷者不求饶、技术流不打玄学谜语、杀伐果断者不说教）；
- **对白是故事的发动机**：对白根据场景动态调节占比（常规 20%~55%，密集智斗/审讯交锋可拉高至 60%~75%，潜行独行求生可降至 5%~15%），让角色在言语机锋中推进剧情。


### 4. 丝滑接戏与章末悬念预留
- **接戏法则**：第一段必须紧密承接上章尾声（`pack ch_XXX` 提供的上章余温），动作、对白、视线与危机毫秒级顺延；
- **章末扣子**：结尾必须停在事件爆发的临界点或收获反转瞬间，为后续精修提供充沛的留白与期待。

## 二、 Drafter 常见误区与避坑指南

- ❌ **误区一：把细纲扩写成“说明文”** ➔ ✅ **正解**：细纲是骨架，起草要填入肌肉与鲜血，多写具体动作、眼神交锋与现场反应。
- ❌ **误区二：主角瞻前顾后、优柔寡断** ➔ ✅ **正解**：主角双商在线、有勇有谋、行事有章法，遇事坚决反击破局。
- ❌ **误区三：所有角色说话语调雷同** ➔ ✅ **正解**：严格参照人物卡声纹锚定，突出不同角色的说话习惯与禁忌。

## 三、 输出与落盘规范（防卡顿铁律）

- 🚨 **必须使用原生 `write_to_file` 工具直接写入** `manuscript/vol_XX/raw/ch_XXX_v1.md`（设置 `Overwrite: true`）；
- 🚨 **严禁使用 `run_command` 执行内联 Python 或 Shell 脚本写入长文本**（防止 Windows 终端非 ASCII 截断报错）；
- 🚨 **非 Artifact 文件严禁传入 `ArtifactMetadata` 参数**；
- **字数范围**：约 2400~3500 字（纯小说 Markdown 格式，以剧情冲突饱满为第一准绳，不硬凑字数）。
