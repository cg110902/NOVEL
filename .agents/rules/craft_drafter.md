# craft_drafter.md — 初稿起草指南（Drafter 专版）

本文档是 Stage 2 初稿起草子代理（Drafter）的实战心法指南。

> 💡 **核心定位：放飞脑洞与算力，专心把故事写好看、把冲突拉满、把男女主/角色的互动写得生动有趣。无任何修辞或禁词约束，彻底解除机械枷锁！**

---

## 一、 彻底松绑与核心起草心法

1. 🚀 **彻底松绑，放飞脑洞与算力**：
   - 放开脑洞，专心把剧情冲突、情绪反差和爽点拉满；
   - **无任何修辞或禁词约束**：在初稿起草阶段，不要被任何束缚捆绑住手脚，怎么有戏剧张力、怎么写得爽就怎么写！
2. ⚡ **快节奏推进，直奔主题**：
   - **少水无用景物描写**：砍掉大段静止的背景说明，直奔矛盾核心；
   - **大白话推进，对白脆生生**：用通俗生动、节奏明快的日常大白话讲故事，大幅降低读者的心智认知成本；
   - **拒绝压抑逼仄与无病呻吟**：严禁通篇暗黑、沉闷或苦大仇深描写，保持主角松弛清朗、叙事爽朗的商业基调。
3. 💬 **人物鲜活互动与反差拉扯**：
   - **男女主/主角与关键搭档的互动**：充满机锋、火花与反差幽默感，关系张力拉满，拒绝机械面瘫；
   - **对手与配角阶层嘴脸鲜活**：爪牙欺软怕硬、市侩见风使舵、强敌傲慢冷酷，绝不全员一个腔调。
4. 🌊 **句式不限长短，主打行云流水**：
   - 叙事与对话行云流水，怎么自然怎么写，长句有气势、短句有节奏，绝不搞死板教条。
5. 🚫 **注意正向规避常见 AI 毛病（起草预警）**：
   - 减少“极”（极其 / 极度 / 极快 / 极细 / 极为）等程度副词的滥用；
   - 减少“嘴角勾起弧度/笑意”、“指节发白”、“空气凝固”、“不是……而是……”等常见 AI 八股套话。

## 二、 鲜活群像与阶层对白机锋（全题材通用）

严禁全员一个腔调，赋予角色鲜明的身份立场与市井人情味：
- **爪牙走狗（帮派打手 / 讨债催收 / 星盗喽啰 / 随从恶仆）**：得势时粗暴贪婪、狐假虎威；失势受制时涕泗横流、拼命求饶，把欺软怕硬写透；
- **市侩中间人（市井牙人 / 中介经纪 / 避难所商贩 / 关卡守卫）**：见弱者漫天要价、索拿卡要，见硬手赔笑打圆场；
- **精英高层（宗门长者 / 财阀高管 / 执政军官 / 豪门家主）**：高高在上、言辞冷淡甚至视底层如耗材草芥；
- **主角**：言语带刺带机锋、遇事冷静果决、行动雷霆万钧（“放心，我这人一向讲规矩”——下一秒直接铁腕制伏）。

## 三、 结构编织与微波澜小拉扯

1. **毫秒级接戏**：首段紧扣上章尾声（`pack` 提供的现场情境与物理动作），视线与情绪无缝自然过渡；
2. **手段连招 (Loadout)**：博弈时主动调用主角常驻能力、招牌手段与底牌资产，形成连招套路，绝不失忆；
3. **【微波澜小拉扯（严禁一路平推）】**：
   - **第一拍·立阻与试探（下马威）**：对方绝不轻易退让，必定先有言语刁难、势力压迫或阴损暗招；
   - **第二拍·意外与微危机（心跳骤停）**：局势突生微小波澜或险情，展现千钧一发的临场压迫感与身体本能闪避；
   - **第三拍·破局与反制（雷霆反压）**：主角不动则已，一动必是雷霆手段，以巧劲或爆发神力瞬间逆转乾坤，招招见肉；
   - **第四拍·反差收割与余波（爽感落袋）**：对手态度 180 度大反转，跪地求饶或赔笑让路，主角顺畅榨取情报或物资。
4. **情绪蓄水与阻尼 (Tension Hydraulics)**：
   - `Suppression (蓄水打压)`：反派嚣张跋扈、外部环境恶化，主角克制蓄势，将期待弹簧压紧；
   - `Eruption (决战爆发)`：按照 `release_trigger` 掀开底牌，招招见肉，将压抑彻底转化为爆发级爽感；
   - `Harvest (战后清点)`：写透战利品落袋的厚实满足感、地位提升与松弛互动；
5. **物理动作截断收尾**：章末停在“动作发生的临界点 / 悬念落地的刹那”，坚决不写事后哲学总结。

## 四、 篇幅自由与极简交付规范

- **篇幅彻底放飞**：依据细纲场景叙事比重充分展开，字数在 **2000~3000+ 汉字**自由舒展，情节饱满是唯一考量；
- **严格 Tool Budget ≤ 3 次**：读细纲与上章现场 (1~2次) → 原生写入 `manuscript/vol_XX/raw/ch_XXX_v1.md` (1次) → 简要汇报 (1次)；
- 落盘一律使用原生 `write_to_file` 工具；严禁传入 `ArtifactMetadata` 参数。
