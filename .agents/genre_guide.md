# genre_guide.md — 题材词汇与翻车点（只供选择，不是公式）

用法：Stage 0 与 Stage 1 的主控读物。每题材四小节都是**素材库**：选中的写进 bible 与
project.json，不选的连理由都不写。任何一条都可以推翻——推翻记得进「本书偏离清单」。
数字给的是手感区间，不是指标；字数带的最终值在 project.json.words_target 里由主控定夺。

## 通用（所有题材共用）

- 开局三件套自选：钩子事件 / 世界规则的一次"演示" / 主角的常态生活
——顺序随意，但在第一章需要三者齐备；把"设定说明会"当开局是多数新手的第一个坑。
- 现代题材也要"系统"：不是金手指，是可复述的规则感（钱、人脉、程序、行规）。
- 跨题材通用的翻车：主角全知全能、配角只为剧情服务而存在、冲突全靠误会推动却没人写
  误会的成本、把题材标签当风格（"这是玄幻"≠"可以写得空洞"）。
 
## 玄幻

- 可玩词汇：境界阶梯 / 宗门与供奉 / 灵材与市价 / 天劫与誓约 / 洞府产权。
- 手感偏好：升级要挂在具体人事上（一个宗门、一笔债、一次护送）；
  战斗章可短、铺垫章可长，别均匀。
- 常见翻车：境界通货膨胀（三步一大境界，读者记不住也没感觉）；打脸循环三连。
- 反套路可选：把"金手指"写成负债（力量要还）；主角所在宗门其实是弱者一方。

## 都市

- 可玩词汇：行规与价目 / 人情账户 / 信息不对称（业内人 vs 外行）/ 时间与通勤。
- 手感偏好：冲突密度靠对话与场合切换，不靠反派排队上门；
- 常见翻车：职场外行话、金手指开挂式创业、把"打工人"当背景板而不是压力源。
- 反套路可选：主角是行业里"快被淘汰的那批"，专业知识反而成了他唯一的武器。

## 悬疑

- 可玩词汇：线索分级（硬证/软证/误导）/ 时间线双账（读者账 vs 真相账）/ 口供的缝隙。
- 手感偏好：信息控制重于氛围渲染；每章末读者手里应有一张可核对的"线索清单"；
- 常见翻车：靠主角降智推进疑云；关键证据在需要时才"恰好"出现（lines 台账会让这种
  赖账现形——plant 得比 resolve 早）；凶手自首式独白收尾。
- 反套路可选：侦探是错的、程序是对的；或案件早早破了，余下全写"破案的代价"。

## 科幻

- 可玩词汇：一个设定的全部下游（技术—制度—习俗—骂人的话）/ 术语预算 / 硬设定软着陆。
- 手感偏好：一章只教一个新概念，用事故教、不用课堂教；
- 常见翻车：说明书式开篇；人类在全设定面前集体失语（文化应该跟着技术变形）。
- 反套路可选：高科技低组织度（技术很硬，社会很烂）；或未来考古视角写当下。

## 言情

- 可玩词汇：关系的度量衡（谁先低头/称谓/未发出的消息）/ 两人都"对"的错位 / 亲密的日常性。
- 手感偏好：进度条是"知情差"的变化——谁知道多少、何时知道；
  误会章要有成本记录（lines 里的 misunderstanding 就是成本账）。
- 常见翻车：靠不沟通拖章数；第三方工具人化；把占有欲写成深情的默认值。
- 反套路可选：开篇即婚后/分手后，写"修复"不写"获取"；或两人各自的事业线真的比爱情难。

## 武侠

- 可玩词汇：江湖规矩与脸面 / 师承与来历 / 镖银与地盘经济 / 招式的物理后账（伤要养）。
- 手感偏好：侠是选择不是武力值；打斗写空间与体力，少写光效；
- 常见翻车：招式名堆砌；门派设定压过人物；"义"字万能收尾。
- 反套路可选：主角是规则的执行者而非挑战者（捕快/中人/牙婆视角）；武功越高越没有江湖。

## 无限流

- 可玩词汇：副本规则文本（逐条可执行）/ 主神经济（积分汇率）/ 队伍信息差 / "通关姿势"复用度。
- 手感偏好：每个副本是一种章型实验场（规则怪谈副本配书信·文书章，武侠副本配动作长镜头）；
- 常见翻车：规则说了不算（作者中途改口）；队友轮流通用化；奖励通胀。
- 反套路可选：主角在副本里攒的是"人"不是"宝"；或第一次副本就输，全书写清算。

## 治愈

- 可玩词汇：季节与食物 / 小事的手感（修好的伞、养活的绿萝）/ 社区的人际温度 / 旧伤与新日常。
- 手感偏好：冲突降级但不取消——用"失去的一点点"驱动；静章配额可全题材最高
  （form 占比里静水流日常章可以奢侈一点，记得偏离清单备案）。
- 常见翻车：鸡汤化（角色互相宣讲幸福）；把苦难当调料浅尝辄止；全员好人导致无事发生。
- 反套路可选：写"没能被治愈也没关系"；或治愈者的职业倦怠。
