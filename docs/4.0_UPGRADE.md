# Novel Studio 4.0 升级说明 — 从 3.3 到 4.0 全面优化

## 一、 升级目标

用户原话：**“全面升级。全面优化这个流程。把engine改的功能非常非常强大，全自动化；使用则非常简单！全程甚至只需要一条命令就行！”**

3.3 痛点：
- 流程重：init → beats new → pack → (Drafter v1 → Editor v2 → Polisher v3 → Auditor+ Critic 并发) → finalize → proposal auto → sync，7 步手动
- 依赖多智能体接力，终端易截断，需物理文件总线
- 新手门槛高，需理解 Stage 0A/0B/0C、双并发、零命令铁律等
- 无 LLM 时无法跑通全流程

4.0 解法：
- **一条命令成书**：`novel` / `one` / `run` 从零到 N 章全自动
- **功能强大**：autopilot + generator + llm + healer + super_engine 五大新内核
- **使用极简**：零参数向导 + 极简参数（书名/题材/主角/脑洞/章数）
- **离线可用**：Mock 生成器保证无 Key 也能成书，有 Key 自动升级

## 二、 新增模块清单

### engine/llm.py — 可插拔 LLM 后端
- `LLMProvider` 抽象：generate(prompt, system, max_tokens, temperature) -> LLMResponse
- `MockProvider`：基于哈希的确定性伪创作，离线可用
- `OpenAIProvider`：自动检测 OPENAI_API_KEY，失败降级 Mock
- `AnthropicProvider`：同上
- `get_provider(prefer="auto")`：auto 优先 openai → anthropic → mock

### engine/generator.py — 智能内容生成器
- `GENRE_BIBLE_TEMPLATES`：玄幻/都市/科幻/悬疑/历史/仙侠 6 套，每套 6 份 bible
- `SmartGenerator`：
  - generate_bible() / write_bible()
  - generate_character_cards() / write_character_cards()：主角 p_001 + 2 配角
  - generate_outlines() / write_outlines()：main_plot + vol_01/outline
  - generate_beats(chapter_num, context)：含 form 轮换、tension 曲线、断章刀口、到期线索
  - generate_chapter_draft(beats, pack, ch_num) -> (v1,v2,v3)：v1 毛坯 1500字 + v2 脱水 + v3 抛光，LLM 可插拔升级
  - generate_audit_report() / generate_critic_note()：8 探针 + 追更便签

### engine/autopilot.py — 全自动驾驶引擎
- `smart_init(workspace, title, genre, protagonist, idea, force, llm_provider)`：
  - 目录结构创建
  - project.json（含 idea 字段） + state 播种 + 主角实体 p_001
  - 调用 SmartGenerator 写 bible/角色/大纲 + 初始 entities 卡
- `_get_next_chapter_num()` / `_load_context_for_beats()`：自动推断卷号、上一章摘要、到期线索
- `run_chapter(book_dir, chapter_num, llm_provider, ...)`：
  - beats 自动生成 → pack 自动装配（fallback beats）
  - draft v1/v2/v3 自动
  - audit/critic 自动
  - finalize 物理落盘 + proposal 最小合法 + sync 合并 + 快照 + inbox 清理
  - 返回 {ok, chapter, steps, elapsed, words, final_path}
- `_self_heal()`：派生表重算、账本校验、索引刷新（每5章）、体检
- `run_batch(book_dir, chapters, start_ch, ..., auto_heal, auto_export)`：
  - 循环 run_chapter，失败触发自愈 + 重试
  - 完成自动导出 export/<书名>.txt
- `one_command(title, genre, protagonist, idea, chapters, workspace, force, llm_provider)`：
  - 打印参数 → smart_init → run_batch → 统计字数 → 导出
  - 一条命令从零到成书

### engine/healer.py — 自愈引擎
- `heal_book(book_dir, deep)`：
  - 派生表重算：compute_derived(book) → save_state derived
  - 账本校验
  - 孤立 inbox 清理：已 final 的提案移至 processed
  - 索引刷新
  - 快照数统计，deep 时创建基线快照
  - project.json 完整性检查

### engine/super_engine.py — 超级引擎 Facade
- `SuperEngine(workspace, llm_provider)`：
  - smart_init / one_command / write_chapter / auto_write / heal / status / export
  - 统一日志：Provider 名称
  - 版本 4.0.0 Codename One-Command Novel

### engine/commands/autopilot.py — CLI 命令
- `cmd_novel` / `cmd_one`：调用 one_command
- `cmd_create`：交互式向导（无 title 时 input）或参数式，调用 smart_init
- `cmd_write`：单章全自动，调用 run_chapter
- `cmd_auto`：批量全自动，支持区间 ch_006:ch_010，支持 -t 新书转调 novel
- `cmd_run`：智能运行，自动判断新书/续写/单书续写/向导

### engine/cli.py — 注册新命令
- COMMAND_HELP 新增 novel/one/create/write/auto/run/heal
- STAGE_MAP 新增 🚀 4.0 一键成书
- RECIPES 新增 4.0 一键成书 + 批量配方
- _build_subparsers 新增 6 个 parser + heal
- cmd_heal 新增
- help 末尾增加 4.0 极简入门提示

### studio.py — 零参数向导
- `_launch_wizard()`：
  - 无参启动时进入
  - 检测现有书，询问是否续写
  - 否则新书向导：书名/题材/主角/脑洞/章数，确认后调用 cli_main(["novel", ...])
- `if len(sys.argv)==1: _launch_wizard()`

### engine/__init__.py
- __version__ 3.3.0 → 4.0.0

## 三、 使用对比

### 3.3（7 步）
```bash
python studio.py init -w workspace/书 -t 书 -g 玄幻 -p 主角
# 手动填 bible/characters/outlines（Architect 0A/0B/0C）
python studio.py beats new ch_001 --write -w workspace/书
python studio.py pack ch_001 -w workspace/书
# 派发 Drafter/Editor/Polisher/Auditor/Critic 子代理（需 Antigravity 环境）
python studio.py finalize ch_001 -w workspace/书
python studio.py proposal auto ch_001 --write --force -w workspace/书
python studio.py sync ch_001 -w workspace/书
# 重复 N 次...
```

### 4.0（1 步）
```bash
python studio.py novel "我的新书" -g 玄幻 -p 林牧 --idea "废柴逆袭" --chapters 10
# 或
python studio.py   # 零参数向导
```

## 五、 兼容性

- 3.x 31 个命令 100% 保留，`init`/`beats`/`pack`/`finalize`/`proposal`/`sync` 等仍可用
- `project.json` 新增 `idea` 字段，旧书缺失不影响（fallback）
- `workspace/` 结构兼容，4.0 生成的书可被 3.x 命令操作
- `AGENTS.md` 约束仍有效，但主控现在可用 `novel` 等超级命令
